# Hosting Guide

## GitHub Pages - recommended

1. Create a public repository named `data-portfolio`.
2. Upload the contents of this folder, keeping `index.html` at the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main`, and select `/root`.
5. Save and wait for the deployment to complete.
6. Add the live portfolio URL to your CV, LinkedIn Featured section, and email signature.

## Local preview

From this folder run `python -m http.server 8000`, then open `http://localhost:8000` in a browser.

## Recruiter sharing checklist

- Lead with the Retail Revenue dashboard.
- Share the root portfolio URL, not a deep file path.
- Keep the repository public and pin the portfolio repository on GitHub.
- Add a one-line project result to each LinkedIn project entry.
