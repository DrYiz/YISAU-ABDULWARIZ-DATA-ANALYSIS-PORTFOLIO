# Titanic Survival Analysis

Passenger-level survival patterns across class, sex, age, and family structure.

## Deliverables
- `dashboard.html`: interactive dashboard
- `analysis.ipynb` and `analysis.py`: reproducible validation workflow
- `report.html` and `report.md`: executive report
- `plots/`: eight high-resolution PNG visualizations
- `data/cleaned_data.csv`: cleaned dataset
